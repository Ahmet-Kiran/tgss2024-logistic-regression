# Youth Employment and Opportunity Inequality Analysis
**Author:** Ahmet KIRAN  
**Technologies Used:** R, Tidyverse, ggplot2, Logistic Regression  

## About the Project
This project examines the employment dynamics of the young and adult population in Turkey using the TGSS2024 survey data. The process starts with Exploratory Data Analysis (EDA). Then, a Logistic Regression model is built to measure the statistical impact of gender, education, and age on employment.

## Key Findings
* **The Gender Factor:** According to the model, a woman is about 2.7 times less likely to participate in employment than a man, even if they have the exact same age, education level, and region.
* **The Age Effect:** The highest employment rate is in the 25-44 age group. After age 45, this rate drops significantly.
* **The Role of Education:** An increase in education level linearly increases the chance of working. However, this increase alone is not enough to eliminate gender inequality.
